PDE XML Cleanup: reference

Applicability contract

Only supported PDE metadata and schema resources are processed. The command visibility is restricted to matching files or projects.

Safety model

XML is parsed structurally; malformed resources or constructs that cannot be rewritten safely are reported or left unchanged.

Known limitations

  • Formatting is intentionally scoped and is not a general-purpose XML pretty printer.
  • Comments, processing instructions, and schema-specific layout should be reviewed after large changes.
  • External entity behavior is not used to infer formatting decisions.

Support information

The Help content is shipped with the same feature version as the runtime plug-in. When reporting a problem, include the Sandbox feature version, Eclipse version, Java version, the smallest reproducing source, and whether bindings were available.
