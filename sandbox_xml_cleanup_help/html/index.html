PDE XML Cleanup

Normalizes supported PDE XML and schema files through cleanup, command, and marker quick-fix integration.

This documentation is installed by sandbox_xml_cleanup_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Targets plugin.xml, feature.xml, fragment.xml, .exsd, and .xsd resources.
  • Normalizes supported whitespace and self-closing-tag forms.
  • Exposes a PDE XML cleanup command in context and main menus.
  • Provides marker resolutions for detected schema cleanup problems.

Where to start

Use XML Cleanup (Sandbox) in a cleanup profile or invoke Clean Up PDE XML from a supported file or project selection.
