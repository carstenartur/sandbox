Sandbox Java Tools

Sandbox extends Eclipse JDT with Java cleanups, quick assists and the TriggerPattern rule engine. This help describes both day-to-day use and the programming interfaces used to create, test and debug transformations.

Safety model

Local rules may rewrite one AST match directly. Coordinated migrations first create a semantic plan, authorize stable AST targets and then execute only rules whose guards agree with that plan. Migrations that affect test discovery can additionally compare framework-neutral execution-tree snapshots before and after the change.

Sandbox deliberately fails closed when bindings, plan values, action schemas or expected target coverage no longer match the source.
