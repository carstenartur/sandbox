Controls and limitations

ControlMeaning
RepositoryRequired server identity, for example demo. A local directory name is not automatically mapped to the server.
Search modeCommits searches messages; Paths searches first-parent changed paths; Java Types, Annotations and Symbols search historical source facets; Semantic and Hybrid use optional vectors.
Search / EnterRun a search against the selected server repository, returning at most 20 rows (10 for semantic/hybrid in the view).
File path / HistoryLook up the exact path in retained history; unchanged blobs can appear in multiple commits.
RefreshRetrieve author commit counts for the entered repository.
Import Repository…Explicitly push local branches and tags to the displayed Git destination. Conflicting updates fail without force-pushing.
Rebuild Server Index…Use the authenticated, repository-scoped rebuild endpoint. The token is used only for this request.

The three views and Semantic Code Search support F1 help. The server is not embedded in Eclipse. Imports are explicit; EGit commits and pulls do not automatically synchronize all local repositories.

Troubleshooting

  • Repository required: enter the identity used for import or Git push.
  • Connection or HTTP error: verify Preferences, server availability and the exact repository name. Errors are not reported as zero hits.
  • HTTP 401 on rebuild: configure JGIT_ADMIN_TOKEN on the server and enter the matching token.
  • Rejected push: the server has a conflicting branch or tag. Choose another destination or reconcile the histories using normal Git tools.
  • No results: check the repository, search mode and committed source. Rebuild only if the server's derived history index needs repair.
  • Semantic model unavailable: check the server's model/runtime prerequisites or use ordinary text search. Set JGIT_EMBEDDING_ENABLED=false to disable model loading.

Java results depend on available project context and local dependencies. Search results are historical records, not proof that current workspace files match. API evolution and other server-only routes are described in the server README; this UI does not expose every library API.
