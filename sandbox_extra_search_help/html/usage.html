Start, import and search

  1. Build the standalone server as described in the server README. For a new local database, start it with:
    JGIT_DB_URL='jdbc:h2:file:./data/jgit' java -jar target/jgit-server.jar --initialize-empty-schema
    Subsequent starts use the same database URL without the initialization flag. Existing databases require the documented adoption procedure.
  2. In Eclipse, open Window → Preferences → Sandbox Git Search. Set the REST base URL (default http://localhost:8080) and Git base URL (default http://localhost:8443/git). The default Git endpoint uses HTTP despite its port number.
  3. Open Window → Show View → Other… → Git Database Index → Git Database Search. Enter a server repository name, for example demo.
  4. Choose Import Repository… in the view toolbar. Select a local Git working directory or bare repository and review the displayed destination before confirming. This uploads committed branches and tags to the server. It does not upload uncommitted working-tree edits, force updates or delete server refs. Choose a new server name for an unrelated repository.
  5. Select Commits, enter a word from a commit message and press Search or Enter. Select Java Types or Symbols to find declarations in historical Java sources. A successful search reports the number of returned results; connection and HTTP failures display an error.

Inspect history and authors

Git File History takes the same repository name and an exact repository-relative path such as src/example/Clock.java. Use a file path rather than a Java class name. The results show each matching commit and blob; renames begin a separate path history.

Commit Analytics accepts a repository name and displays author names, email addresses and commit counts after Refresh.

Semantic code search

Open Search → Search… → Semantic Code Search. Supply a repository and query. Semantic uses an optional embedding model, Hybrid combines text and vector rankings, and Similar Code expects a blob object ID. The first enabled semantic request can download the model and initialize its native runtime. Ordinary text searches need no model. Hybrid falls back to text when embeddings are unavailable.

Rebuild a server index

Rebuild Server Index… reconstructs the selected repository's derived history index from server-side Git data. Enter the server's JGIT_ADMIN_TOKEN when prompted; Eclipse does not save it. A rebuild can prune indexed history that is no longer reachable. Stop other server writers as described in the server README. This action neither uploads local commits nor modifies Git refs.

All network operations run in background jobs. Use Eclipse's Progress view to cancel work. Cancellation cannot undo a Git push already accepted by the server.
