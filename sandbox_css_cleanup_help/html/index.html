CSS Cleanup

Formats CSS, SCSS, and LESS resources with an explicitly configured Prettier installation.

This documentation is installed by sandbox_css_cleanup_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Provides Explorer context actions for CSS, SCSS, and LESS files.
  • Uses Prettier rather than a separate in-process formatter implementation.
  • Provides an Eclipse preference page for formatter configuration.
  • Writes the formatted resource through the Eclipse workspace APIs.

Where to start

Configure CSS Cleanup in Preferences, then select a .css, .scss, or .less file and choose the matching Format ... with Prettier context action.
