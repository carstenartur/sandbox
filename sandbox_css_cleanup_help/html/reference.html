CSS Cleanup: reference

Applicability contract

The selected resource extension must be supported and the configured Prettier command must be available to the Eclipse process.

Safety model

Formatting can be reviewed in version control. The action should not be used as a semantic minifier or as a replacement for stylesheet tests.

Known limitations

  • Prettier installation and plug-in support for the selected language are external prerequisites.
  • Project-specific Prettier configuration can change the resulting layout.
  • This is a resource action, not a JDT Java cleanup tab.

Support information

The Help content is shipped with the same feature version as the runtime plug-in. When reporting a problem, include the Sandbox feature version, Eclipse version, Java version, the smallest reproducing source, and whether bindings were available.
