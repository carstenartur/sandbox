Code Patterns and Hint DSL

Applies built-in and DSL-defined source transformations and provides rule mining, quick assists, a wizard, a view, and optional LLM-assisted rule inference.

This documentation is installed by sandbox_triggerpattern_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Runs built-in cleanups for string simplification, threading, shift ranges, string comparison, logging diagnostics, obsolete collections, hashCode contracts, and constructor calls.
  • Loads transformation rules from .sandbox-hint files.
  • Offers Generate DSL Rule from Selection as a Java quick assist.
  • Provides Refactoring Mining commands and the Refactoring Mining view.
  • Provides an LLM Rule Inference preference page for explicitly configured providers.

Where to start

Use Code Patterns (Sandbox) in a JDT cleanup profile. Hint files can also be created from the New wizard or from a Java editor selection.
