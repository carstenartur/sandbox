Using Code Patterns and Hint DSL

Entry point

Use Code Patterns (Sandbox) in a JDT cleanup profile. Hint files can also be created from the New wizard or from a Java editor selection.

When it is offered

Each built-in cleanup and each hint rule defines its own syntactic and semantic trigger. Rules that cannot be matched or validated are not applied.

Recommended workflow

  1. Enable only the transformation options you intend to evaluate.
  2. Run the cleanup on a small, version-controlled selection.
  3. Inspect the preview or diff before accepting the change.
  4. Compile and execute the relevant tests.
  5. Expand the scope only after the result is understood.
