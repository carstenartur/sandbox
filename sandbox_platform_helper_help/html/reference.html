Platform Status: reference

Applicability contract

A proposal is created only for constructor forms for which the replacement can be resolved from bindings and mapped to an equivalent factory call.

Safety model

The cleanup refuses conversions whose less common status fields cannot be represented by the selected factory method.

Known limitations

  • Custom subclasses and indirect factory wrappers are outside the matching scope.
  • Availability depends on the Eclipse Platform API level on the project's build path.
  • Binary compatibility of downstream code is not changed; only source calls are rewritten.

Support information

The Help content is shipped with the same feature version as the runtime plug-in. When reporting a problem, include the Sandbox feature version, Eclipse version, Java version, the smallest reproducing source, and whether bindings were available.
