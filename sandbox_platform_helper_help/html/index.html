Platform Status

Modernizes verbose Eclipse Platform status construction to the supported status factory APIs.

This documentation is installed by sandbox_platform_helper_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Recognizes supported new Status(...) construction patterns.
  • Replaces them with concise Eclipse Platform status factory methods where equivalent.
  • Preserves severity, message, exception, plug-in identifier, and code where the target factory supports the same semantics.
  • Runs as a cleanup or save action.

Where to start

Open Java > Code Style > Clean Up, edit a cleanup profile, and select Platform Status (Sandbox).
