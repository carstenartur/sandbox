Platform Status

Modernizes Eclipse Platform Status construction while preserving observable status data and expression evaluation.

This documentation is installed by sandbox_platform_helper_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Recognizes supported five-argument Status constructors whose code is provably IStatus.OK.
  • Uses Status.info, Status.warning, or Status.error when bundle identity, overload, and target type are proven equivalent.
  • Otherwise retains the explicit String or Class identity in the shorter four-argument constructor.
  • Never replaces a nonzero or unresolved application code.
  • Runs as an Eclipse cleanup or save action with the standard preview, Apply, and Undo workflow.

Why fewer parameters can be equivalent

A factory still supplies severity, code IStatus.OK, and the calling bundle identity. Removing explicit arguments is safe when those values and the omitted expression evaluation are proven equivalent. The cleanup uses a constructor fallback whenever that proof is incomplete.

Where to start

Open Java > Code Style > Clean Up, edit a cleanup profile, and select Platform Status (Sandbox).
