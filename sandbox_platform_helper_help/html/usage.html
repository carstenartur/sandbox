Using Platform Status

Entry point

Open Java > Code Style > Clean Up, edit a cleanup profile, and select Platform Status (Sandbox). The configuration preview shows the enabled factory-method form; the execution preview shows the actual source edits before they are applied.

Representative transformation

A supported Status constructor with a binding-resolved severity can be replaced by the corresponding Eclipse Platform factory method.

Before

import org.eclipse.core.runtime.IStatus;
import org.eclipse.core.runtime.Status;

IStatus status = new Status(
    IStatus.WARNING,
    "com.example.plugin",
    IStatus.OK,
    "Could not load preferences",
    exception);

After

import org.eclipse.core.runtime.IStatus;
import org.eclipse.core.runtime.Status;

IStatus status = Status.warning(
    "Could not load preferences",
    exception);

Semantic boundary

The factory call preserves the selected severity, message, and throwable. It does not carry the constructor's explicit plug-in identifier or an arbitrary status code. The Platform factory derives the plug-in identity from the calling bundle and uses the factory's status-code contract. Accept the rewrite only when that is the intended behavior.

When no change is made

  • The constructed type is not exactly the supported Eclipse Status type or its binding cannot be resolved.
  • The severity has no supported factory mapping, for example a cancel status.
  • The constructor shape contains information for which the cleanup has no supported target representation.
  • The required Eclipse Platform factory API is not available on the project's build path.

Recommended workflow

  1. Enable Platform Status (Sandbox) in a dedicated cleanup profile.
  2. Run the cleanup on a small, version-controlled selection.
  3. Inspect every changed call in the execution preview, especially the former plug-in identifier and status code.
  4. Compile and run the error-handling and logging tests that consume the resulting status.
  5. Expand the scope only after the implicit plug-in identity is confirmed for the project.
