Method Reuse: reference

Applicability contract

Candidates must be available in the configured search scope and must match the required inputs, output, visibility, and static/instance context.

Safety model

A textual similarity is not sufficient: unsupported side effects, exception differences, evaluation ordering, or access constraints reject the candidate.

Known limitations

  • Complex semantic equivalence and cross-workspace discovery are outside the current deterministic scope.
  • Very large search scopes can increase analysis cost.
  • Candidates should be reviewed for readability and API intent, not only mechanical equivalence.

Support information

The Help content is shipped with the same feature version as the runtime plug-in. When reporting a problem, include the Sandbox feature version, Eclipse version, Java version, the smallest reproducing source, and whether bindings were available.
