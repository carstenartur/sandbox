Method Reuse

Extracts repeated statement sequences into a shared private method or replaces an inline sequence with a call to an already existing compatible method.

This documentation is installed by sandbox_method_reuse_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Finds repeated contiguous statement sequences above a configurable minimum length.
  • Uses Eclipse JDT Extract Method to create the common method and replace every semantically valid duplicate.
  • Maps varying local names to generated method parameters through JDT's binding-aware duplicate machinery.
  • Keeps a separate mode for reusing an already existing method without creating a new one.

Where to start

Open Java > Code Style > Clean Up, edit a cleanup profile, and select Method Reuse (Sandbox).
