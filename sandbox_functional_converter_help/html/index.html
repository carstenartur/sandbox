Functional Converter

Converts supported imperative loop patterns into Java Stream pipelines.

This documentation is installed by sandbox_functional_converter_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Recognizes supported enhanced-for and related loop patterns.
  • Builds stream operations such as filtering, mapping, matching, collecting, and terminal actions.
  • Preserves encounter order where the source construct requires it.
  • Provides a preview through the standard JDT cleanup profile editor.

Where to start

Open Java > Code Style > Clean Up, edit a cleanup profile, and select Functional Converter (Sandbox).
