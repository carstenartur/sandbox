Functional Converter: reference

Applicability contract

The cleanup is conservative around mutation, control-flow exits, exception behavior, ordering, and variable capture. It runs only when the source pattern maps to a supported stream form.

Safety model

Loops with unsupported side effects, non-local control flow, or uncertain evaluation ordering are left unchanged.

Known limitations

  • A stream expression is not always clearer or faster than the original loop; use the preview and project conventions.
  • Parallelization is not introduced.
  • Complex nested loops and arbitrary mutations may remain imperative.

Support information

The Help content is shipped with the same feature version as the runtime plug-in. When reporting a problem, include the Sandbox feature version, Eclipse version, Java version, the smallest reproducing source, and whether bindings were available.
