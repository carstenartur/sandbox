JUnit Migration: reference

Applicability contract

The cleanup requires resolvable JUnit types and only rewrites patterns for which a supported Jupiter equivalent has been implemented.

Safety model

Tests with custom runners, rules, parameterization, ordering, or lifecycle assumptions are treated conservatively and require review.

Known limitations

  • Adding or updating the JUnit Jupiter dependency is a build-system task and is not inferred blindly.
  • Custom JUnit 4 runners and rules may need dedicated migrations.
  • The migrated test suite must be executed; source-level conversion alone cannot validate test semantics.

Support information

The Help content is shipped with the same feature version as the runtime plug-in. When reporting a problem, include the Sandbox feature version, Eclipse version, Java version, the smallest reproducing source, and whether bindings were available.
