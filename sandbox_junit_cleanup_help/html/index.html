JUnit Migration

Migrates supported JUnit 3 and JUnit 4 test code to JUnit Jupiter.

This documentation is installed by sandbox_junit_cleanup_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Migrates supported JUnit 3 inheritance and JUnit 4 annotations to Jupiter.
  • Converts supported assertions, assumptions, expected-exception forms, lifecycle annotations, and imports.
  • Uses bundled hint rules for common JUnit 5, assumption, and annotation migrations.
  • Provides a standard JDT cleanup preview before changes are applied.

Where to start

Open Java > Code Style > Clean Up, edit a cleanup profile, and select JUnit Migration (Sandbox).
