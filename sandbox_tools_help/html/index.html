Iterator to Enhanced For

Replaces canonical iterator-driven loops with enhanced for loops.

This documentation is installed by sandbox_tools_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Recognizes canonical iterator declaration, condition, and next() use.
  • Introduces an enhanced-for variable with the resolved element type.
  • Removes iterator boilerplate when the iterator has no remaining use.
  • Integrates with the standard JDT cleanup execution pipeline.

Where to start

Enable the Sandbox tools cleanup in a JDT cleanup profile, then run Source > Clean Up... on the selected Java elements.
