Iterator cleanup reference

The historical Sandbox implementation replaces canonical iterator-driven loops with enhanced for loops.

This cleanup has been contributed to Eclipse JDT UI and is maintained there. Current Sandbox versions deliberately do not contribute a second org.eclipse.jdt.ui.cleanup.toolscleanup implementation.

Current runtime ownership

  • The active cleanup is the standard implementation supplied by Eclipse JDT UI.
  • The Sandbox source and regression tests remain in the repository for historical comparison.
  • The installable Sandbox feature remains available as a reference, cheat sheet, and update path for older installations.
  • Updating the existing feature replaces the former Sandbox bundle and therefore removes its duplicate runtime contribution.

Where to start

Use the normal Eclipse Java cleanup profile and enable the standard JDT option that converts eligible iterator/loop forms to enhanced for loops. Run it through Source > Clean Up....
