Using the maintained iterator cleanup

Entry point

  1. Open or select Java source containing an explicit iterator loop.
  2. Choose Source > Clean Up....
  3. Configure a normal Eclipse JDT cleanup profile.
  4. Enable the standard JDT option for conversion to enhanced for loops.
  5. Review the preview and apply the change.

There is no separate Sandbox cleanup option or Sandbox Tools cleanup tab.

Representative result

Before

Iterator<String> iterator = values.iterator();
while (iterator.hasNext()) {
    String value = iterator.next();
    consume(value);
}

After

for (String value : values) {
    consume(value);
}

Review workflow

  1. Start with a small, version-controlled selection.
  2. Inspect the Eclipse cleanup preview or resulting diff.
  3. Verify imports, comments, element type, and loop body.
  4. Compile and run the relevant tests.
  5. Expand the scope only after the behavior is understood.
