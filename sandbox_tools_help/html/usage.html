Using Iterator to Enhanced For

Entry point

Enable the Sandbox tools cleanup in a JDT cleanup profile, then run Source > Clean Up... on the selected Java elements.

When it is offered

The iterator must represent one collection traversal and must not be manipulated in ways that an enhanced-for loop cannot express.

Recommended workflow

  1. Enable only the transformation options you intend to evaluate.
  2. Run the cleanup on a small, version-controlled selection.
  3. Inspect the preview or diff before accepting the change.
  4. Compile and execute the relevant tests.
  5. Expand the scope only after the result is understood.
