Mathematics report destinations

The headless mathematics application writes a JSON report even in analysis mode. Source analysis is read-only; the requested report itself is an output file. Select a destination outside project resources and workspace metadata.

eclipse -nosplash -application sandbox_math_cleanup.analysis \
  -data /work/workspace \
  --project Example --config /work/math.properties \
  --report /work/reports/math-analysis.json

Protected locations

The report must not overwrite the configuration, compilation units, or resources of any registered workspace project, including other projects and closed project roots. Project directories and the workspace .metadata directory are protected even when the requested report file or one of its parent directories does not yet exist. Linked locations of accessible projects are protected as well. The preflight checks aliases of known protected files, including hard links, and resolves existing symbolic parents. Unresolvable or dangling symbolic links are rejected.

For example, do not select /work/workspace/OtherProject/.classpath, /work/workspace/.metadata/report.json, or /work/workspace/Example/new/report.json. Use a sibling directory such as /work/reports/ instead. Reports may be updated at an existing unprotected external destination. Filesystem roots and directories are not report files.

Failure and concurrency

An unsafe destination causes the application to fail before analysis and before writing the report or applying source edits. The preflight itself does not create directories or modify files. This protection is not isolation from concurrent filesystem changes: do not change project locations or filesystem links during a run. Inaccessible resources cannot provide a complete inventory of external aliases; use a dedicated report directory, not a hard link to a workspace file.

These destination rules apply to both analysis and --apply. They do not grant consent for checked arithmetic or authorize source edits. See headless use and diagnostics for the separate application and safety options.
