Using Headless Cleanup Application

Entry point

Launch Eclipse with application id sandbox_cleanup_application.org.sandbox.jdt.core.JavaCleanup, a workspace supplied through -data, and one or more workspace files or directories.

Command-line example

eclipse -nosplash -application sandbox_cleanup_application.org.sandbox.jdt.core.JavaCleanup -data <workspace> --mode check -config cleanup.properties <files-or-directories>

Use --mode check or --mode diff before enabling write mode in automation.

When it is offered

Inputs must resolve to Java-like files inside the selected Eclipse workspace. The same cleanup bundles that provide the configured options must be installed in the application.

Recommended workflow

  1. Enable only the transformation options you intend to evaluate.
  2. Run the cleanup on a small, version-controlled selection.
  3. Inspect the preview or diff before accepting the change.
  4. Compile and execute the relevant tests.
  5. Expand the scope only after the result is understood.
