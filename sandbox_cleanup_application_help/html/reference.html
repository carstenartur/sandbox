Headless Cleanup Application: reference

Applicability contract

Inputs must resolve to Java-like files inside the selected Eclipse workspace. The same cleanup bundles that provide the configured options must be installed in the application.

Safety model

Use --mode check or --mode diff in CI before enabling write mode. Keep the workspace and source tree under version control.

Known limitations

  • Files outside the selected workspace are skipped.
  • Cleanup keys are Eclipse JDT cleanup option keys and must match the installed platform and cleanup bundles.
  • The feature has no interactive UI and therefore no SWTBot screenshot.

Support information

The Help content is shipped with the same feature version as the runtime plug-in. When reporting a problem, include the Sandbox feature version, Eclipse version, Java version, the smallest reproducing source, and whether bindings were available.
