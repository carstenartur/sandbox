Headless Cleanup Application

Runs installed Eclipse JDT and Sandbox cleanup implementations from an Equinox command line without opening the workbench.

The Help bundle is installed by sandbox_cleanup_application_feature together with the runtime. The runtime plug-in does not depend on the Help bundle.

Operational contract

  • Application id: org.sandbox.jdt.core.JavaCleanup.
  • Supports apply, read-only check, and read-only diff.
  • Can import one checked-out Eclipse project into a disposable workspace.
  • Resolves main/test scope to concrete Java files before cleanup starts.
  • Can write a unified patch and a JSON report with changed files and errors.
  • Returns 0 for success, 1 for any error, and 2 only for required changes without an error.

Safe starting point

Run --mode check with a version-controlled project, a disposable -data workspace, --import-project, and a JSON report. Treat exit code 1 as execution failure and exit code 2 as a cleanup-policy failure.
