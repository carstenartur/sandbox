Headless Cleanup Application

Runs Eclipse JDT cleanup profiles from an Equinox command line without opening the full IDE.

This documentation is installed by sandbox_cleanup_application_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Supports apply, check, and diff modes.
  • Reads cleanup options from a Java properties file.
  • Can write a unified patch and a JSON report.
  • Supports main/test/both scope filtering and quiet or verbose output.
  • Uses exit code 2 when check or diff mode detects required changes.

Where to start

Launch Eclipse with application id sandbox_cleanup_application.org.sandbox.jdt.core.JavaCleanup, a workspace supplied through -data, and one or more workspace files or directories.
