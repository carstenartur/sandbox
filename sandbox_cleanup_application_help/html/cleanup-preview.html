Cleanup preview model

The cleanup workflow has two distinct previews:

  • The profile configuration tab preview, which shows a small static example for the selected options.
  • The real execution preview shown after Source > Clean Up..., which lists concrete changes.

Independent local changes

When the proposed edits are local and semantically independent, the execution preview allows selecting or deselecting individual files and individual text-edit groups. The selected subset is applied when finishing.

Coordinated multi-file migrations

Some migrations require an atomic all-or-nothing selection across files. That coordinated contract is tracked separately in carstenartur/sandbox#1451.
