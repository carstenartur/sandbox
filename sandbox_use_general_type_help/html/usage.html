Using Use General Type

Entry point

Open Java > Code Style > Clean Up, edit a cleanup profile, and select Use General Type (Sandbox). The configuration preview demonstrates the selected cleanup; the execution preview shows the declaration and import changes for the current source selection.

Representative transformation

The cleanup widens a declaration only when every binding-resolved use is available through the proposed API type.

Before

import java.util.ArrayList;

ArrayList<String> names = new ArrayList<>();
names.add("Ada");
int count = names.size();

After

import java.util.ArrayList;
import java.util.List;

List<String> names = new ArrayList<>();
names.add("Ada");
int count = names.size();

Only the declared type changes. The concrete construction expression and runtime collection remain an ArrayList. A separate cleanup or semantic migration is required to change the representation itself.

Target selection

The target is derived from the operations that are actually used, not from a fixed class-to-interface table. For example, a LinkedList used through deque operations such as addFirst can be widened to Deque, while ordinary list operations can lead to List.

When no change is made

  • A cast or instanceof check observes the concrete declared type.
  • The value is returned, assigned, or passed to a declaration that still requires the concrete type and is outside the supported local change.
  • Overload selection, generic constraints, reflection-sensitive code, or unresolved bindings make the wider type uncertain.
  • No useful abstraction exposes every required member.

Recommended workflow

  1. Enable Use General Type (Sandbox) in a dedicated cleanup profile.
  2. Start with local variables in a small source selection.
  3. Inspect the execution preview to confirm the selected abstraction and import changes.
  4. Compile and run tests that exercise overloads, serialization, and framework integration around the declaration.
  5. Use a coordinated multi-file migration rather than this local cleanup when method signatures and callers must change together.
