Use General Type

Replaces overly specific declared types with a compatible, more general API type where supported.

This documentation is installed by sandbox_use_general_type_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Analyzes the members actually used through a declaration.
  • Chooses a compatible superclass or interface that still exposes the required API.
  • Updates supported local, field, parameter, or return declarations according to the implemented scope.
  • Keeps construction expressions unchanged unless a separate cleanup handles them.

Where to start

Open Java > Code Style > Clean Up, edit a cleanup profile, and select Use General Type (Sandbox).
