Use General Type: reference

Applicability contract

A more general type must preserve all statically resolved member access and assignment constraints in the analyzed scope.

Safety model

The cleanup rejects candidates affected by overload selection, generic incompatibility, casts, reflection-sensitive declarations, or missing binding information.

Known limitations

  • Public API changes may affect binary/source compatibility outside the workspace.
  • A technically general type is not automatically the best domain abstraction.
  • Frameworks that inspect declared types through reflection require manual review.

Support information

The Help content is shipped with the same feature version as the runtime plug-in. When reporting a problem, include the Sandbox feature version, Eclipse version, Java version, the smallest reproducing source, and whether bindings were available.
