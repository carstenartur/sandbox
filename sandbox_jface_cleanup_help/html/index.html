JFace API Modernization

Migrates supported deprecated JFace API uses to current equivalents.

This documentation is installed by sandbox_jface_cleanup_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Recognizes supported deprecated JFace calls from resolved method and type bindings.
  • Rewrites them to current API equivalents.
  • Adjusts imports and arguments when required by the supported migration.
  • Labels independent migration steps separately in the real Cleanup preview.
  • Can run as a cleanup or save action.

Where to start

Open Java > Code Style > Clean Up, edit a cleanup profile, and select JFace Cleanup (Sandbox).

Configuration in Eclipse

This configuration image uses the fixed example preview. To inspect actual project files, run the cleanup and continue to the real Cleanup execution preview.
