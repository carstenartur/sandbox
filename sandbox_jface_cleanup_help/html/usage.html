Using JFace API Modernization

Entry point

Open Java > Code Style > Clean Up, edit a cleanup profile, and select JFace Cleanup (Sandbox).

When it is offered

A migration is offered only when the source invocation resolves to a known JFace API signature and an equivalent replacement is available.

Recommended workflow

  1. Enable only the transformation options you intend to evaluate.
  2. Run the cleanup on a small, version-controlled selection.
  3. Inspect the preview or diff before accepting the change.
  4. Compile and execute the relevant tests.
  5. Expand the scope only after the result is understood.

Real execution preview (LTK)

The profile tab preview above is only an example snippet. The actual execution preview appears after Source > Clean Up... and lists the concrete file/step changes that will be applied.

Independent local changes may be deselected per file or per step. Coordinated multi-file migrations keep a separate atomic-selection contract tracked by carstenartur/sandbox#1451.

See Cleanup preview model for the shared behavior details.
