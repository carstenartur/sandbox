Using JFace API Modernization

Entry point

Open Java > Code Style > Clean Up, edit a cleanup profile, and select JFace Cleanup (Sandbox). Enable the master option and then choose one or more of the three migrations below it.

When it is offered

A migration is offered only when the source invocation resolves to a known JFace API signature and an equivalent replacement is available.

Recommended workflow

  1. Enable only the transformation options you intend to evaluate.
  2. Run Source > Clean Up... on a small, version-controlled selection.
  3. Continue to the real execution preview.
  4. Select each affected file or named cleanup step and inspect its diff.
  5. Deselect only independent local changes that you do not want to apply.
  6. Compile and execute the relevant tests.
  7. Expand the scope only after the result is understood.

Named preview steps

The execution preview uses separate user-facing labels for the SubProgressMonitor, ViewerSorter, and ImageDataProvider migrations. This makes several independent changes in one file reviewable without exposing internal cleanup option identifiers.

Screenshot regeneration

The images in this Help bundle are generated from a real Eclipse workbench by AllHelpScreenshotsSWTBotTest. Run the Maven profile help-screenshots under Xvfb to regenerate them after UI changes. The test also applies the selected preview changes and verifies refactoring undo.
