JFace API Modernization: reference

Applicability contract

A migration is offered only when the source invocation resolves to a known JFace API signature and an equivalent replacement is available.

Safety model

The cleanup does not replace unrelated methods that merely share a name. Ambiguous overloads and unsupported behavior differences are left for manual review.

Known limitations

  • Coverage is limited to the migrations implemented by this bundle.
  • Projects targeting older JFace versions may not provide the replacement API.
  • UI behavior should be verified with the application's SWT/JFace tests.

Support information

The Help content is shipped with the same feature version as the runtime plug-in. When reporting a problem, include the Sandbox feature version, Eclipse version, Java version, the smallest reproducing source, and whether bindings were available.
