Explicit Encoding

Replaces platform-default or string-based charset usage with explicit, type-safe charset handling.

This documentation is installed by sandbox_encoding_quickfix_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Keeps the original behavior where an explicit charset is already part of the call.
  • Can insert StandardCharsets.UTF_8 for supported platform-default APIs.
  • Can aggregate supported explicit UTF-8 spellings to StandardCharsets.UTF_8.
  • Runs as a normal JDT cleanup and can also be enabled for save actions.

Where to start

Open Java > Code Style > Clean Up, edit a cleanup profile, and select Explicit Encoding (Sandbox).
