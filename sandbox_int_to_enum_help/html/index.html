Int to Enum

Migrates supported integer-constant domains and their usages toward Java enum types.

This documentation is installed by sandbox_int_to_enum_feature together with the runtime plug-in. The runtime plug-in does not depend on this Help bundle.

What the feature provides

  • Detects supported groups of related integer constants.
  • Analyzes compatible declarations, assignments, comparisons, and switch usage.
  • Introduces or uses an enum representation when the observed data flow is closed over the detected domain.
  • Updates supported call sites consistently within the analyzed scope.

Where to start

Open Java > Code Style > Clean Up, edit a cleanup profile, and select Int to Enum (Sandbox).
